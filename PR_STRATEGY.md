# MiniBrowser — Public Relations & Launch Strategy

The browser for people tired of slow, RAM-hungry browsers.
Built by **Sandeep Ghosh** — [Trendzza](https://advertisewith.trendzza.in/founder).

## 1. Message (the one-line story)

> Every browser in 2026 is a Chromium fork that hoards RAM. MiniBrowser is a
> native Swift/WebKit macOS browser that uses 0.8–1.5 GB for 20 tabs — free,
> non-commercial, no telemetry.

**Core hero numbers (always lead with these):**
- 20 tabs: **0.8–1.5 GB** vs Chrome's **6–10 GB**
- First page: **<0.3s pre-warmed** vs Chrome's **1–3s cold start**
- Network-layer ad/tracker blocking (ads never downloaded)
- `⌘K` command palette, Web Inspector, UA switching, localhost discovery

## 3. Execute next — high-impact launch directories (free, but need a quick signup)

These give the biggest "launch moment" and SEO backlinks. Each needs a free
account. Do them in order on **one day** to create a launch spike:

1. **Product Hunt** — producthunt.com. Make a maker profile, add 2–3 screenshots,
   a maker comment (the founder story), and pick a launch date. Tags: macOS,
   Productivity, Open Source. Include lots of GIFs of tab hibernation + RAM HUD.
2. **Hacker News "Show HN"** — news.ycombinator.com. Post a text post titled
   `Show HN: MiniBrowser – a native macOS browser that uses 0.8 GB for 20 tabs`.
   Put the story + a download link in the first comment. Best posted 7–8am PT.
3. **r/macapps + r/mac** (Reddit) — text post with the story + GitHub link.
   Honest, no hype, no "upvote please."
4. **r/opensource** (Reddit) — focus on the single-file Swift codebase for devs.
5. **Tolodora** (tolodora.com) — free, "live the moment you submit," permanent page.
6. **LaunchFree.io** (The Runway) — free launch directory for dev tools.

## 7. Notes & caveats

- **License:** Free forever, **non-commercial** — you may not sell it. This is
  intentional. Some open-source directories (e.g. OSSDrop) require an **OSI**
  license and will reject a custom non-commercial license. That's a tradeoff of
  the "no commercial reuse" choice. dal.ink (which we submitted to) does NOT
  require an OSI license, so it's the right fit.
- **Zero telemetry** is a strong differentiator — say it everywhere.
- The app is ad-hoc signed (not notarized). Get a Developer ID + notarize
  (`notarize.sh` is ready, needs a paid Apple account) so installs are clean —
  this removes the #1 objection people will raise in comments.
